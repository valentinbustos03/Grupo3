# Assets

Logo del dashboard. Guardá el logo de Grupo3 acá como **`assets/logo.png`**
(idealmente PNG con fondo transparente; también acepta `logo.svg`, `logo.webp`,
`logo.jpg`).

El masthead lo carga automáticamente (`grupo3/dashboard/componentes.py::_logo_html`)
y lo muestra en el hueco al lado de "Grupo3". Si no hay archivo, muestra un
placeholder punteado con la palabra "logo".
